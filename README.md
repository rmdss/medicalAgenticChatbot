# medicalAgenticChatbot

**Overview**

This project implements a full-stack Medical AI Chatbot that can answer medical questions, retrieve information from PDF documents, search the web for additional information, understand uploaded images, and interact through voice using Agentic AI, Retrieval-Augmented Generation (RAG), LangGraph, Pinecone Vector Database, Tavily Search, FastAPI.

The project was developed as a hands-on learning exercise based on a tutorial, https://www.youtube.com/watch?v=9AlsksEQuWM&t=6685s by DSWithBuppy. I used it to understand how building AI agents, integrating large language models (LLMs), implementing retrieval-augmented generation (RAG), and orchestrating AI workflows work in practice.
